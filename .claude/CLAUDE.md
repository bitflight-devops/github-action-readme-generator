# Claude Code Project Configuration

## Agent Restrictions

- **Explore agent is BANNED** - Use `context-gathering` agent instead for codebase exploration tasks

## PR Workflow

- Draft PRs get zero real review — CodeRabbit posts "Review skipped: Draft detected" and stops; humans generally skip drafts too.
- Draft is the correct starting state (per the standing instruction to open PRs as draft), but it is not the resting state.
- Once you have applied your own review pass to a PR's changes (read the diff, checked for the kind of issues you'd flag in someone else's PR), mark it ready for review — don't leave it in draft indefinitely waiting for something else to happen.
- Concretely: call the "mark ready for review" / `draft: false` update on the PR as soon as your own review pass is done, in the same session, not "later."
